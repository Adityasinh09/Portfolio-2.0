## Overview

Designed a high-fidelity mobile application UI/UX concept for a task management tool, prioritizing user interaction clarity and minimalist visual design.

## Design Highlights

- Successfully transitioned from **low-fidelity wireframes** to a comprehensive high-fidelity design system.
- Optimized visual hierarchy to enhance task persistence and interaction clarity across all key screens.
- Applied **color theory** and micro-interaction principles to create an engaging, distraction-free experience.

Figma · Visual Hierarchy · Color Theory · Prototyping · Motion Design
