## Overview

Designed a full responsive e-commerce platform focused on conversion-driven design, intuitive user flows, and a striking visual identity for a fashion retail brand.

## Design Highlights

- Utilized a **vibrant color palette and bold typography** to create a visually striking, brand-forward interface.
- Designed a full **product discovery flow**: homepage → category → product detail → checkout, optimized for conversion.
- Ensured high functionality and intuitive user flows across multiple device formats (mobile, tablet, desktop).

Figma · Prototyping · Responsive Design · Color Theory · Visual Hierarchy
